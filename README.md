# JobsifyAI job feed

Public XML feed of open JobsifyAI jobs for job aggregators (Jooble, Adzuna, Careerjet).
Rebuilt daily at 06:00 IST by GitHub Actions from https://www.jobsify.ai/sitemap.xml.

Feed URL (GitHub Pages): https://the-knowledge-artisans.github.io/jobsify-feed/jobs.xml

Apply links go to the JobsifyAI job page. Do not put anything confidential in this repo; it is public.
